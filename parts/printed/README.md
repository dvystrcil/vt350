# Printed parts: every part this build prints

One folder holds every printed part, ready to slice (#63). The list of what to print is
[`bom/printed-parts.md`](../../bom/printed-parts.md) (#8 AC2): every "print" row there is a part here, or a link
when the part isn't copied. Parts that the bought Monolith CNC kit, Trident Backbone and kinematic bed mount replace
are left out.

- **`manifest.csv`**: one row per part: file, qty, **stage** (the stage issue #7–#15 where it's installed, read by the
  docs generator in #40), source repo, pinned commit, upstream path, sha256, licence.
- **`<source>/`**: unchanged upstream files, each folder with the upstream `LICENSE` and a `README.md` (repo, commit,
  upstream paths, "our changes: none").
- **`vt350/`**: our remixes, under the licence of the part each was made from ([`vt350/README.md`](vt350/README.md)
  says which `lite-N` each comes from).

`parts/check-printed.py` checks all of this in CI (sha256s, files not in the manifest, rows without a file, "print"
rows without a part, stages, licences). The table below is generated from `manifest.csv` by
`parts/check-printed.py --write-index`; edit the manifest, not the table.
